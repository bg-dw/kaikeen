# KAIKEEN

Peta 3D jaringan otak dari project GitHub bg-dw — 46 repo, 732 aksi terpetakan.

Buka di web: https://bg-dw.github.io/kaikeen/

## Cara pakai

- Klik neuron project → node controller muncul; klik controller → node function; klik function → node model; klik model → node tabel database.
- Tombol **Layar penuh** untuk view 3D, pencarian global lintas project, breadcrumb + tombol Kembali di kiri atas 3D.
- Panel samping: bagian **Isi controller** (semua function + penjelasan + model + tabel) dan kotak alur **function → model → database** beserta isi kolom tabel.
